Conexion con GitHub

Para escribir directamente en bodega-vinos.json el editor necesita un token personal tuyo. Se guarda unicamente en este navegador y solo se usa para hablar con la API de GitHub.

  1. En GitHub: foto de perfil, Settings, Developer settings, Personal access tokens, Fine-grained tokens, Generate new token.
  2. Repository access: Only select repositories, y elige Cash-Record-Virtual.
  3. Permissions, Repository permissions, Contents: Read and write. Nada mas.
  4. Genera el token, copialo y pegalo aqui abajo.
