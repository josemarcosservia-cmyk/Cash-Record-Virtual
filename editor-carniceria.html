Conexión con GitHub

Para escribir directamente en carniceria-productos.json necesitas un token personal de GitHub.

  1. En GitHub: foto de perfil → Settings → Developer settings → Personal access tokens
  2. Acceso al repositorio: Solo repositorios seleccionados → Elige Cash-Record-Virtual
  3. Permisos → Contenido: Lectura y escritura
  4. Copia y pega el token aquí
