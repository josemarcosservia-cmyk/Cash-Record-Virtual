Conexión con GitHub

Para escribir directamente en carniceria-productos.json necesitas un token personal de GitHub. Se guarda en tu navegador, nunca se envía a servidores.

  1. En GitHub: foto de perfil → Settings → Developer settings → Personal access tokens → Fine-grained tokens
  2. Repository access: Only select repositories → Elige Cash-Record-Virtual
  3. Permissions → Repository permissions → Contents: Read and write
  4. Genera el token, cópialo y pégalo aquí
